# Analyse par type de séance

Selon `session_type`, l'analyse doit mettre en avant :

- **ef / recuperation** : allure conversationnelle, FC Z1–Z2, pas de pic inutile
- **sortie_longue** : volume, dérive FC, hydratation/météo
- **tempo / seuil** : proximité allure cible prévisions, régularité
- **fractionne / vma** : splits, récupérations, cadence si dispo
- **cotes** : D+, effort relatif
- **competition / test** : perf vs prévisions distances
- **non classé** : inviter à taguer ; analyse générique distance/allure/FC

Ne jamais inventer cadence/FC absentes du JSON activité.
