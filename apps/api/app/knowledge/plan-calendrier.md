# Construction d'un plan calendrier

Objectif : 7–14 jours, **3 à 7 séances**, réaliste vs charge récente.

Règles :
1. Respecter la catégorie analytics (charge élevée → plus de récup / EF).
2. Alterner intensité / facilité ; pas deux séances dures consécutives.
3. Utiliser les `session_type` du catalogue (ef, seuil, fractionne…).
4. Proposer allures cibles **issues du contexte prévisions**, pas inventées.
5. Dates à partir d'aujourd'hui (ISO YYYY-MM-DD).
6. Si peu de tags : rester prudent, favoriser EF + 1 qualité max.

Format JSON plan : date, session_type, title, details, target_pace, duration_or_distance.
